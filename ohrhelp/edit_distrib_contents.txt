Here you can modify which files get put in each exported package (.zip, .tar.gz or .exe installer).

By default a README-<package_name>.txt file is generated from the information in the `Edit distribution info' menu. But if you want to write your own README, Omit the autogenerated one and add an Extra File.

You can also Omit or Include the LICENSE.txt file which is a copy of of the license selected in Edit Distribution Info, if any. There's no actual need to include a copy of the Creative Commons licenses, and most people don't. You should 

LICENSE.txt is separate from LICENSE-binary.txt which is a mandatory copy of the OHRRPGCE's license (dual-licensed MIT or GPLv2).

The paths to Extra files are relative to the .rpg itself, but these paths are stripped out. All the selected files and directories will be placed directly next to the game. E.g. if you include a "promo/manual" directory which contains "promo/manual/title.png", "manual/title.png" is added to packages.
